# Microsoft Rewards Script v4.2.3

## 更新内容

- **更新日志状态条新增积分展示**：
  - 主界面状态条显示「今日获得」与「当前积分」，数字采用彩色显示（正常为绿色，0 或异常为红色），与计划任务状态配色一致。
  - 账号下拉框显示完整邮箱，右侧与「清理日志」按钮对齐。
- **静默运行与通知**：
  - 支持静默窗口模式（勾选=静默隐藏，半选=最小化，未选=正常窗口）。
  - 支持 Windows 通知（勾选=启动+完成都通知，半选=仅完成通知，未选=不通知）。
  - 修复启动通知不弹与误报“运行失败”导致 last-run-date 不更新的问题。
- **更新日志链接可点击**：
  - 更新日志中的链接（GitHub 仓库、完整更新对比）点击即在默认浏览器打开。
  - 列表项符号 `?` 与 `-` 统一显示为 `•`，排版更紧凑。

## 历史修复

- **v4.2.2**：修复管理程序自动更新下载失败（TLS 1.2/1.3、重试、错误提示）；修复 Dependabot 安全漏洞（4 high + 2 moderate）。

## 既有功能

- **版本更新页「项目主页」按钮**：点击即在浏览器打开 GitHub 仓库。
- **自动更新**：点击「立即更新」从 GitHub Release 下载最新便携版并自动覆盖安装，保留 `.env`、`config.json`、`node_modules`、`logs` 等用户数据。
- **RewardsManager 图形化管理程序**：首次启动自动检测运行环境，提供一键安装依赖与浏览器、计划任务管理、版本更新检查。
- **autorun 一键运行工具**：通过 Windows 计划任务每日自动运行脚本。
- **中文本地化**：搜索词与运行时输出信息已中文化。

## 快速开始

1. 下载并解压 `Microsoft-Rewards-Script-portable-v4.2.3.zip`
2. 双击 `autorun/RewardsManager.exe`
3. 按向导用 `.env.example` 生成 `.env` 并填入账号；首次运行会自动安装 Node / 依赖 / 浏览器内核
4. 在管理程序中配置计划任务，实现每日自动执行

> 修改 `.env` 或 `config.json` 后需重新构建，可在管理程序中重跑「安装依赖并构建」。
